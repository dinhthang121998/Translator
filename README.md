# 📱 Translator

A powerful and modular Android application that allows users to translate text by typing, from static images, and in real-time using CameraX. Built with modern Android architecture and machine learning tools.

---

## ✨ Features

- 🔤 **Text Input Translation** — Translate typed words instantly.

- 📷 **Image Translation** — Extract and translate text from static images using ML Kit OCR.

  <img width="200" height="444" alt="Screenshot_20250715_144630" src="https://github.com/user-attachments/assets/48796ba8-7c24-440d-86c9-57d9d643b332" />

  [Screen_recording_20250715_144841.webm](https://github.com/user-attachments/assets/e33172b4-2d38-4bfc-a1b8-88df0dfb2224)
- 🗣 **Text-to-Speech Support** — Speak translated words aloud.
- 💾 **Favorites** — Save frequently used translations.

  <img width="200" height="444" alt="Screenshot_20250715_145002" src="https://github.com/user-attachments/assets/c03566fa-9aba-4215-a9f9-9d1bafcd93a1" />
- 🔒 **Encrypted Storage** — Securely store user data using Cipher and Jetpack Datastore.
- 📡 **Remote API Support** — Connect to translation services using Retrofit. Reference: https://dictionaryapi.dev/

---

## 🛠 Tech Stack

- **Language:** Kotlin
- **Architecture:** MVVM (Model-View-ViewModel)
- **Machine Learning:** ML Kit
- **Camera:** CameraX
- **Persistence:** Room, Jetpack Datastore (with Proto)
- **Networking:** Retrofit
- **Encryption:** Cipher
- **Dependency Injection:** Hilt
- **Speech:** TextToSpeech
